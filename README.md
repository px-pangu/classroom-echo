## 1. 这是什么

面向大班课（300 人级别）的**匿名提问与课后回顾系统**。它解决的是三个结构性矛盾：

1. **想问不敢问** —— 大课提问有社交成本，越是需要问的人越沉默；
2. **教师无法兼顾** —— 讲课不能停，余光扫 iPad 的时间只有几秒，界面必须极简；
3. **疑问课后蒸发** —— 没答完的问题散在群里，下节课开头的五分钟无从下手。

系统按**五个角色端**分别设计，每个端的交互上限都被写死（学生 2 次点击、教师首屏 3 个按钮、助教导出 1 次点击）。

### 当前版本的性质

- 单文件纯前端，双击 `index.html` 即可运行，**不含任何外部网络请求**；
- 五个角色端以可切换视图呈现，内置演示疑问数据；
- 语义聚类、录屏切片关联、二维码轮换等为**方案设计目标**（见验收指标），原型不含后端与 WebSocket 服务；
- 当前版本**不使用 localStorage**，刷新即回到初始演示状态。

## 4. 五个角色端详解

### 01 学生提问端

- **角色**：大课在读本科生，怕被点名的沉默提问者。
- **页面**：扫码落地单屏 —— 课程名、讲课时间戳、一行提问框、热问卡片流。
- **操作**：扫码进入**零注册**；≤ 60 字提问后提交，秒回「已并入第 X 号疑问」；可对已有卡片 +1 或撤回。
- **后台逻辑**：去停用词转向量，与本讲候选簇做余弦比对，**≥ 0.82 并入并计数 +1**，否则建新簇；热度 = 计数 × 时间衰减；写入走一次性匿名票据。
- **隐私**：IP、设备指纹、学号**一律不采集**；无 cookies、无登录态；票据仅含随机 ID 与教室号，10 分钟失效。
- **验收**：≤ 2 次点击、≤ 15 秒完成提问；聚类返回 P95 ≤ 3s；300 并发写失败率 < 0.5%；匿名计数零误差。

### 02 教师课堂端

- **角色**：主讲教师，讲课不停顿，只用余光扫 iPad。
- **页面**：单屏三键操作栏 + 按热度降序的疑问队列；投影端为高对比大字视图。
- **操作**：全程**只有三个按钮** —— 标记已答、课后答、上屏追问；队列默认选中热度第一。
- **后台逻辑**：新簇到达按热度重排并闪烁提示 3 秒；已答下沉、课后答写入未答表；操作时同步记录当前录屏时间戳。
- **隐私**：教师视图、口播与投影**只显示问题文本与计数**；任何接口不返回提问者 IP、设备指纹、学号或座位位置。
- **验收**：首屏恒为 3 个按钮；单条处理 ≤ 1 次点击；重排延迟 ≤ 1s；投影模式对比度 ≥ 7:1、正文字号 ≥ 28px。

### 03 助教课后端（迭代版）★

- **角色**：课程助教，负责下节课开头五分钟的回顾。
- **页面**：一键生成的未答清单，**按课程章节分组**，附 3 道回顾题。
- **操作**：下课后点「生成清单」，一键复制或导出 Markdown 交教师。
- **后台逻辑**：读取未答与课后答簇，用聚类标签匹配课程章节序号，按知识点自动归类；按热度取前 3 生成回顾题，每题含建议用时、答点与「来源：#X 号疑问」。
- **迭代点**：由「课后生成未答问题清单」升级为「清单 + 按知识点自动归类到课程章节 + 生成 3 道可用于下节课开头的回顾题」。
- **验收**：下课后 ≤ 30 秒出清单；知识点归类覆盖率 ≥ 90%；3 道题各 ≤ 120 秒可讲完；导出一次点击完成。

### 04 回放回顾端

- **角色**：课后复习的学生，以及补课重看录播的同学。
- **页面**：左侧疑问列表 + 右侧录屏播放器与同步板书切片。
- **操作**：点疑问即跳转到对应回放时刻并切换板书；可对该疑点继续 +1（匿名累加）。
- **后台逻辑**：簇绑定提问时刻的时间戳，自动关联最近板书页与录屏切片；回放期计数并入同一簇并重排热度。
- **验收**：点击到起播 ≤ 1.5s；时间轴定位误差 ≤ 3s；切片同步命中率 ≥ 95%；30 天内录像均可检索。

### 05 课程管理后台

- **角色**：教务与课程负责人，管课次、录源与合规。
- **操作**：建课生成动态二维码；接入或关闭录屏源；设置数据留存天数；导出匿名统计。
- **后台逻辑**：二维码**每 10 分钟轮换**且只绑定课次；源接入后逐帧生成板书切片索引；留存到期只保留匿名计数与知识点标签。
- **验收**：300 并发下写请求 P95 ≤ 500ms；聚类端到端 P95 ≤ 3s；禁用策略不可开启**可验证**；学期数据导出 ≤ 60s。

## 5. 视觉与体验规范

| 项 | 取值 |
|---|---|
| 底色 | 浅灰 `#F5F6F4` |

| 并发 | 300 人同时匿名提问 |
| 聚类响应 | ≤ 3 秒 |
| 教师端首屏 | 恒为 3 个操作按钮 |
| 学生端 | ≤ 2 次点击 |

---

## 6. 硬约束（设计红线）

1. **不显示任何提问者身份**，禁止采集 IP、设备指纹、学号；
2. **无积分、无排行榜、无签到打卡**；
3. **不强制注册、不索取通讯录**；
4. **教师删除问题时必须保留匿名计数**（只移除文本，不清空计数）。

---

## 7. 隐私设计总表

| 数据 | 处理方式 |
|---|---|
| IP 地址 / 设备指纹 / 学号 | 默认且**强制关闭**，不可开启 |
| 提问者身份 | 任何接口不返回，导出包剔除时间戳以外的一切个体痕迹 |
| 票据 | 仅含随机 ID 与教室号，10 分钟失效 |
| 板书切片 | 去除笔迹中的个人信息 |
| 观看进度 | 存本地，不同步 |
| 校外域名回调 | 不可回调 |

---

## 8. 已知限制

- 原型不含后端，5 个角色端为同一页面内的视图切换，无真实并发与 WebSocket；
- 语义聚类阈值 0.82 为设计取值，原型未接入向量模型；
- 录屏与板书源接入为界面演示，不含真实媒体处理。
