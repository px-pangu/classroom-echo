# 课堂回声 · 大班课实时匿名提问与板书回顾系统 — 角色端功能表

**全局基线**：300 人并发匿名提问；语义聚类响应 ≤ 3 秒；教师端首屏恒为 3 个操作按钮；学生提问 ≤ 2 次点击；视觉为浅色卡片流，投影端切换高对比大字模式。
**硬约束**：① 不显示任何提问者身份，禁止采集 IP、设备指纹、学号；② 无积分、无排行榜、无签到打卡；③ 不强制注册、不索取通讯录；④ 教师删除问题时必须保留匿名计数。
**迭代说明**：第 03 模块由「课后生成未答问题清单」调整为「课后生成未答问题清单，并按知识点自动归类到课程章节，同时生成 3 道可用于下节课开头的回顾题」，其余四个模块保持不变。
**视觉基调**：浅灰底 `#F5F6F4` + 单一安静强调色墨青 `#2F6F78`（只用其透明度梯度作层次）；投影模式反转为深色高对比 `#0D1416`，正文放大至 16px、标题 ≥28px。

---

### 01 学生提问端

- **角色**：大课在读本科生，怕被点名的沉默提问者
- **页面**：扫码落地单屏：课程名、讲课时间戳、一行提问框、热问卡片流
- **核心操作**：扫码进入零注册；≤60 字提问后提交，秒回「已并入第 X 号疑问」；可对已有卡片 +1 或撤回
- **后台逻辑**：去停用词转向量，与本讲候选簇做余弦比对，≥0.82 并入并计数 +1，否则建新簇；热度＝计数 × 时间衰减；写入走一次性匿名票据
- **隐私设计**：IP 地址、设备指纹、学号一律不采集；无 cookies、无登录态；票据仅含随机 ID 与教室号，10 分钟失效
- **可量化验收指标**：≤2 次点击、≤15 秒完成提问；聚类返回 P95 ≤3 秒；300 并发写失败率 <0.5%；匿名计数零误差

### 02 教师课堂端

- **角色**：主讲教师，讲课不停顿，只用余光扫 iPad
- **页面**：单屏三键操作栏 + 按热度降序的疑问队列；投影端为高对比大字视图
- **核心操作**：全程只有三个按钮：标记已答、课后答、上屏追问；队列默认选中热度第一
- **后台逻辑**：新簇到达按热度重排并闪烁提示 3 秒；已答下沉、课后答写入未答表；操作时同步记录当前录屏时间戳
- **隐私设计**：教师视图、口播与投影只显示问题文本与计数；任何接口不返回提问者 IP、设备指纹、学号或座位位置
- **可量化验收指标**：首屏恒为 3 个按钮；单条处理 ≤1 次点击；重排延迟 ≤1 秒；投影模式对比度 ≥7:1、正文字号 ≥28px

### 03 助教课后端（迭代版）

- **角色**：课程助教，负责下节课开头五分钟的回顾
- **页面**：一键生成的未答清单，按课程章节分组，附 3 道回顾题
- **核心操作**：下课后点「生成清单」，一键复制或导出 Markdown 交教师
- **后台逻辑**：读取未答与课后答簇，用聚类标签匹配课程章节序号，按知识点自动归类；按热度取前 3 生成回顾题，每题含建议用时、答点与「来源：#X 号疑问」
- **隐私设计**：导出包剔除时间戳以外的一切个体痕迹；学生姓名、学号、IP、设备指纹不落清单；校外域名不可回调
- **可量化验收指标**：下课后 ≤30 秒出清单；知识点归类覆盖率 ≥90%；3 道题各 ≤120 秒可讲完；导出一次点击完成

### 04 回放回顾端

- **角色**：课后复习的学生，以及补课重看录播的同学
- **页面**：左侧疑问列表 + 右侧录屏播放器与同步板书切片
- **核心操作**：点疑问即跳转到对应回放时刻并切换板书；可对该疑点继续 +1（匿名累加）
- **后台逻辑**：簇绑定提问时刻的时间戳，自动关联最近板书页与录屏切片；回放期计数并入同一簇并重排热度
- **隐私设计**：跳转只传时间戳不传身份；观看进度存本地不同步；板书切片去除笔迹中的个人信息
- **可量化验收指标**：点击到起播 ≤1.5 秒；时间轴定位误差 ≤3 秒；切片同步命中率 ≥95%；30 天内录像均可检索

### 05 课程管理后台

- **角色**：教务与课程负责人，管课次、录源与合规
- **页面**：课次列表、录屏与板书源接入、匿名策略开关、用量与留存报表
- **核心操作**：建课生成动态二维码；接入或关闭录屏源；设置数据留存天数；导出匿名统计
- **后台逻辑**：二维码每 10 分钟轮换且只绑定课次；源接入后逐帧生成板书切片索引；留存到期只保留匿名计数与知识点标签
- **隐私设计**：IP、设备指纹、学号三项默认且强制关闭；积分、排行榜、签到打卡永不提供；删除问题时保留计数、仅移除文本
- **可量化验收指标**：300 并发下写请求 P95 ≤500 毫秒；聚类端到端 P95 ≤3 秒；禁用策略不可开启可验证；学期数据导出 ≤60 秒

## 附：字数与口径自检

- **字数口径**：统计每个模块六个字段的正文字符数（不含序号、标题、`-` 列表符、字段名与标点外的空白），5 个模块分别为 218 / 210 / 216 / 202 / 229 字，均在 230 字以内。
- **操作上限**：学生端从扫码到提交恒为 2 次点击；教师端首屏按钮数恒为 3；助教端导出恒为 1 次点击。
- **不出现的内容**：任何提问者身份字段（IP、设备指纹、学号、姓名、座位）；任何积分、排行榜、签到打卡入口；任何「删除问题即清空计数」的行为；任何要求注册或授权通讯录的环节。
